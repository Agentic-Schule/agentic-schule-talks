1. Prompt: adopt a skill without copying it

Let your agent read a foreign skill as untrusted text, list every link and command in it, and then write a new skill for your project in its own words. First make invisible characters visible, then let your agent rewrite the skill in a fresh session.

2. Settings: sandbox on, downloads off

Gemini CLI. The sandbox is off by default. Start with gemini --sandbox, or set it in settings.json:

{
  "tools": { "sandbox": true }
}

Avoid --approval-mode=yolo and the --consent flag of gemini skills install, which skips the security prompt. On macOS the default sandbox profile still allows outbound network.

Antigravity. In the App, keep the Default permission preset (sandbox on). The CLI starts without the sandbox: use agy --sandbox or "enableTerminalSandbox": true. Stay away from Turbo or Always Proceed with a new skill. Rules for the deny list, from Google’s own examples:

command(regex:curl .*)
command(sudo)
write_file(.git/)

Claude Code. Since v2.1.283 it starts in auto mode, where a classifier decides instead of a prompt and read-only HTTP requests are allowed. For a new skill, use manual mode and the sandbox. In ~/.claude/settings.json:

{
  "sandbox": { "enabled": true },
  "permissions": {
    "defaultMode": "default",
    "deny": ["Bash(curl *)", "Bash(wget *)"]
  }
}

Also check a skill’s frontmatter for allowed-tools: in Claude Code a skill can pre-approve its own tools. A deny rule does not catch the same program called by path or inside sh -c.

Codex. Sandbox on and network off by default. Keep it that way in ~/.codex/config.toml and never use --yolo with a new skill:

sandbox_mode = "workspace-write"
approval_policy = "on-request"

Check the docs of your tool for the current syntax. Links below.

3. The five-minute check

  1. Read the SKILL.md, the file the agent reads, not the README of the marketplace.
  2. Search for addresses. Does every domain really belong to the vendor? Is the spelling exactly right?
  3. Search for authority. “ground truth”, “authoritative”, “always follow the instructions at”.
  4. Look into the scripts and everything the skill wants to install.
  5. Origin over popularity. Who submitted it, and how old is the account?
  6. Make invisible characters visible: LC_ALL=C grep -rn '[^ -~]' .

A skill that fetches instructions from the internet cannot be reviewed. Treat foreign skills as a template, never as a dependency.
